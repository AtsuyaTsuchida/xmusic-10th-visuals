# x-music-collage

> **このリポジトリに入っているもの**: 映像アプリ(`video/app`)・再生ソフト(`video/player`)・道具(`tools`, `video/tools`)のソースと説明書きだけ。
> 音源、動画素材、研究室のロゴ、脳のメッシュと CT 画像、書き出した動画は入れていない(他の人の作品や、実在の人のデータを含むため)。
> 動かすには、自分の音源と素材を、各説明書きにある場所に置く。


x-Music Lab の作品映像から抜き出した音声(`../x-music-videos/audio/`)の断片だけで作った曲。
ドローン/アンビエントで始まり、少しずつ脈が生まれて、ブレイクビーツに変わり、最後にまたほどける。

- テンポ 150 BPM、188 小節(ちょうど 5 分)、G メジャー/E マイナー寄り。完成版は `x-music-collage_v2.wav` / `.m4a`
- `x-music-collage_v7.wav` / `.m4a` は、v6 を 7 分に伸ばした版(下の「v7」)。`song.py` は既定で v7 を組む
- `x-music-collage_v6.wav` / `.m4a` は、v5 と同じ構成でキックだけ変えた版(下の「v6」、5 分)。`XMC_STYLE=v6 python3 song.py トラック名…` で組める
- `x-music-collage_v5.wav` / `.m4a` は、構成ごと変えた版(下の「v5」): 中盤ジューク → 後半テクノの四つ打ち → キックが詰まっていって一打で終わる。`XMC_STYLE=v5 python3 song.py KIT mix` で v5 のドラムに戻せる
- `x-music-collage_v3.wav` / `.m4a` は、v2 のビートを四つ打ち寄りにしたもの(下の「v3」)。`XMC_STYLE=v3 python3 song.py KIT mix` で組む。`XMC_STYLE=v2` なら v2 のドラム
- `x-music-collage_v4.wav` / `.m4a` は、ビートをジューク/フットワークにしたもの(下の「v4」)。`XMC_STYLE=v4 python3 song.py LOOPS KIT mix` で組む
- v1(168 小節、4 分 32 秒)も残してある。v2 ではビートを強め、断片の切り口が途切れて聞こえないようにし、5 分に伸ばした
- `x-music-collage_v1_5min.wav` / `.m4a` は、v1 の音作りのまま v2 と同じ 5 分構成にしたもの。`XMC_STYLE=v1 python3 song.py トラック名…` で組める(v1 の粒は `cut_v1_grains.py` が `grain_v1` フォルダに切り出す)。録音後は `XMC_STYLE` なしで組み直して v2 に戻す
- 音はすべて Ableton Live の中で鳴らしている(Simpler / Drum Rack + Live 標準エフェクト)。
  Python は「解析」「断片の切り出し(加工なし)」「Live の操作」だけで、音の合成や加工はしていない。

| 33–64 | 0:51 | Stirring | ドローンにトレモロがかかり脈打ちはじめる。濾したループ、鼓動のキック |
| 65–96 | 1:42 | Pulse | ハーフタイムのビート。フィルタが開き、ベースとドラムの断片が入る |
| 97–112 | 2:34 | Break | フルのブレイクビーツ |
| 113–128 | 2:59 | Chop | ドラムループを拍単位で並べ替える |
| 129–144 | 3:25 | Peak | いちばん密な部分 |

## v3: 四つ打ち寄りのビート

v2 から変えたのは KIT の音符だけ(音作り、他のトラック、構成は同じ)。

- Break / Chop / Peak / Final: キックを毎拍(1・2・3・4拍)に置く。v2 の跳ねたキックは、小節ごとに1〜2個だけ軽く残す(`KX`)
- スネア(2・4拍)、ゴースト、ロール、ドラムループの並べ替えはそのまま。ブレイクビーツの上に四つ打ちのキックが乗る形
- ハットは裏拍(8分の裏)を強く、表を弱くした
- Pulse の終わり 8 小節(89–96)で、四分のキックが少しずつ大きくなって入ってくる
- Breakdown と Dissolve はハーフタイムのまま

録音は `XMC_ONLY=KIT stems.py ../work/stems_v3 0 302`(KIT とマスターだけ)。頭の 300 秒を 24bit にしたものが v3。

## v4: ジューク/フットワークのビート

v2 から変えたのは KIT と LOOPS の音符だけ。テンポは 150 のまま(ジュークは 160 前後が普通だが、曲の長さと他のトラックを保つため変えていない)。

- キックは 3-3-2 系の位置(例: 16分で 1・4・7・11・15 番目)。ベースのフレーズと同じ位置に置いた小節が基本(`JK`)
- クラップ役のスネアは 2・4拍、または4拍目だけ。ハットは裏拍、ところどころ1拍を3連で刻む
- ロールと連打は 16分3連(最後の1拍はその倍)。Peak では3拍目に3連のキックが入る小節がある
- Chop からは3つ刻みのリム、Peak からはタムが加わる
- Pulse / Breakdown はクラップが3拍目に来るハーフタイム。キックが 1 → 1・7 → 1・4・7・11 と増える
- LOOPS のドラムループは拍ごとの並びをやめ、3-3-2 の位置で断片を鳴らす。4小節の終わりは3連で6回

録音は `XMC_ONLY=KIT,LOOPS stems.py ../work/stems_v4 0 302`。

## v5: ジューク → 四つ打ち → 詰めて終わる

テンポ 150、長さ 5:00 のまま。96 小節目までは v4 と同じ。全トラックを組み直す(`python3 song.py SUB GLASS … STAB mix`、15分)。

| 小節 | 時間 | 内容 |
|---|---|---|
| 1–96 | 0:00 | ドローン → 脈 → ハーフタイム(v4 と同じ) |
| 97–128 | 2:34 | ジューク(v4 のパターン。後半ほど密) |
| 129–172 | 3:25 | テクノの四つ打ち。キック毎拍、クラップ 2・4拍、裏拍のハット。ドラムループの断片は鳴らさない。ベースは裏拍の8分 |
| 173–186 | 4:35 | キックが 8分(173–180)→ 16分(181–185)→ 32分(186 後半)と詰まっていく |
| 187 | 4:57.6 | 頭で一打(キック、和音、ベース、クラッシュ)。ドローンはここで止める |

- 引く部分・ほどける部分はない。上物は Peak の状態のまま最後まで続く
- 一打のあと 5:00 までに響きが収まるよう、179–183 小節で長い残響(HALL / GRAIN)への送りを 0 まで絞っている。Live の返りトラックは曲の途中で音量を動かせないため
- `song.py` の中では実際の 145 小節目以降を 301 以降の番号で書く(`X()`)。v2 までの終盤(145–216)は曲の外へ飛ばして捨てる
- Live セットのロケーター(Break、Dissolve など)は v2 のまま残っている

## v6: キックの音と数

v5 から変えたのは KIT の音符だけ。

- キック役の音符(kick_1 / kick_2 / kick_4)は、すべて kick_4 + snare_1 を同時に鳴らす重ねにした。kick_3 はタムとして使っているので残す
- 2・4拍のスネアは snare_1 + snare_2 のまま
- ビートのある小節には必ずキックを2つ以上: 鼓動(49–64)は2つ打ち、ハーフタイムの入り(65–72)は3拍目の裏にもう1つ。1つだけなのは最後の一打(187)
- kick_4 は軽い音なので、60Hz より下は v5 より約4dB 少ない
- 録音の前に Live でソロが入っていないか確かめること(1回目はソロで KIT だけが録れた)。`stems.py` はソロがあると録音せずに止まる

## v7: 7 分版

v6 の音符と自動化をそのまま作ってから、決めた位置に「直前の 8 小節のくり返し」を差し込んで伸ばす(`INSERTS`、合計 75 小節)。テンポは 150 のまま、263 小節。

| 小節 | 時間 | 内容 | v6 での長さ → v7 |
|---|---|---|---|
| 1–48 | 0:00 | ドローン | 32 → 48 小節 |
| 49–96 | 1:17 | うごめき(脈、鼓動のキック) | 32 → 48 |
| 97–144 | 2:34 | ハーフタイム | 32 → 48 |
| 145–192 | 3:50 | ジューク | 32 → 48 |
| 193–244 | 5:07 | テクノの四つ打ち | 44 → 52 |
| 245–261 | 6:30 | キックが詰まっていく | 14 → 17 |
| 262 | 6:57.6 | 一打して終わり | |

- 差し込む位置は、区間の中の 8 小節のまとまりの境目。各段階(だんだん密になる順)を1回ずつ多く鳴らす形で、段階が後戻りしないようにしてある
- くり返す区間の中に収まる音符は写し、境目をまたいで鳴り続ける長い音(ドローン)は差し込んだぶん長くする。自動化は、差し込んだ区間の間は境目の直前の値のまま保つ
- 盛り上げの音(ROAR)やノイズの刻みが切り替わる小節の境目は避けてある。差し込む位置を変えるときは、段階のある自動化(`step=True`)がその境目で切り替わっていないか確かめること
- 録音は `XMC_ONLY=KIT stems.py ../work/stems_v7 0 422`、頭の 420 秒を 24bit にしたものが v7

## v8: 手で直した版の書き出しとマスタリング

v7 を `orf2026_xmusiclab_edit.als` として保存したあと、Live 上で手で直した状態(トラックの追加・ミュート、KIT の音符の削除など)を、そのまま録音したもの。`song.py` からは作り直せない(Live セットが正本)。

- `x-music-collage_v8.wav` … 録音したままの音(7:00)。約 -10.0 LUFS、ビートの部分は -7 LUFS 台
- `x-music-collage_v8_master.wav` / `.m4a` … マスタリングしたもの。約 -11.2 LUFS、ピーク -1.0 dBTP
- マスタリングは `tools/master.sh 入力 出力`(ffmpeg だけ): 24Hz より下を切る → 4.5kHz あたりを 2dB 抑える → ゆっくり効く圧縮(比 1.6)で大きい部分を下げて全体を持ち上げる → 4倍の細かさでピークを -1 dBTP に収める
- 効き方: 静かな出だし(0〜2分)は 2〜3dB 上がり、ビートの部分は 1.3〜2dB 下がる。音量の幅(LRA)は 11.9 → 7.9
- 録音は `XMC_ONLY_MASTER=1 stems.py ../work/stems_v8 0 424`。手で直したセットでは、録音の前にループを切り、録音待機を外し、終わったら戻す(`work/live_state_before_export_20261120.json` に元の状態)

## 6 分版: 最後の連打の残響から 1 分のアンビエント

`orf2026_xmusiclab Project/orf2026_xmusiclab_edit_6min.als`(2026-11-21)。5 分版の複製を Live で開き、`tools/tail.py` で終わりに余韻を足した。
**API からは保存できないので、Live で ⌘S するまでファイルの中身は 5 分版のまま。**

```sh
cd tools && python3 tail.py        # 開いているセットに書く。何度実行してもよい(引数でドローン全体の dB を上げ下げ)
```

- 手で直した結果、曲の終わりは「一打」ではなく 16 分の連打が 742 拍(4:56.8)まで続く形だった。余韻はその終わりから数える。
- 4 本目のリターン `D-Reverb`(減衰 30 秒、100% ウェット、低域カット)を足した。送るのは最後の連打(740-742 拍)とドローンだけで、曲のほかの部分には送っていない。
- 連打の 2 拍のクリップは、同じノートのクリップに置き換えて送りのオートメーションを付けた(アレンジメント上のクリップには API からオートメーションを書けないので、セッション側で作って置く)。
- SUB / GLASS / ORBIS / CHORD / AIR を連打の直後から立ち上げ、AIR → GLASS → CHORD → ORBIS → SUB の順に引いて 60 秒で消す。クリップは 904 拍(小節 227 の頭)まで。全体は 5:57。
- 752 拍から先は、セットのテンポのオートメーションが 160 BPM になっている(手で置かれたもの、そのまま)。拍に合う音は無いので聴こえ方には影響しないが、秒と拍の換算は `tail.py` の `beat()` / `sec()` で合わせてある。
- 実測(終わりを録音、`work/tail_check6/`): 連打の区間 -12 dBFS(RMS)→ 直後 -22 → 11〜44 秒 -20 前後 → 47 秒 -25 → 53 秒 -33 → 59 秒 -53 → 62 秒 -60。聴いての確認はしていない。
- **はまった点 1(0.5 秒おきの「ザク」)**: `write_automation` は点と点の間を 0.25 拍の段で埋める。点の間隔が 0.25 拍の倍数でないと端数が埋まらず、そこだけ元の値(Utility なら 0 dB)に跳ねる。秒で点を置いたら 160 BPM の区間で 0.5 秒ごとに 31 ms の隙間ができ、ドローンが一瞬大きく鳴っていた。点は拍の格子(1 拍ごと)に置き、最後の点は `tail` でクリップの終わりまで伸ばす(`place()` で検査している)。
- **はまった点 2(終わりに大きく鳴る)**: クリップの終わりを過ぎると Utility は 0 dB に戻る。ノートをクリップの終わりまで伸ばすと、離したあとの余韻(4〜6 秒)が 0 dB で鳴る。ノートは余韻ぶん手前で切る。
- 原因の切り分けで `D-Reverb` に 2 台目のリバーブを足したが、関係がなかったので切ってある(Device Off)。API からは消せないので、Live 上で削除してよい。
- GLASS には 16 分の速いトレモロ(深さ約 48%)がかかったまま(曲の後半のオートメーションが 896 拍まで続いているため)。余韻では不要なら、GLASS の余韻クリップに Amount 0 を書けば切れる。

## 作り直し方

Live を起動して空のセットを開いた状態で:

```bash
cd tools
V=../../glitch-house-generate-main/.venv/bin/python   # numpy / librosa / soundfile 入り
$V scan.py ../../x-music-videos/audio ../work/scan    # 素材の解析(数分)
$V cut.py  ../../x-music-videos/audio ../work/scan    # 断片を User Library/Samples/XMusicCollage に切り出す
python3 song.py all                                   # Live 上に全トラックを組み立てる(15分ほど)
caffeinate -d -i $V stems.py ../work/stems 0 302      # 全トラックとマスターを実時間で録音(スリープすると途中で切れる)
$V report.py ../work/stems/MASTER.wav
```

`song.py TRACK名` で 1 トラックだけ作り直せる(`all` を 2 回やるとマスターのエフェクトが重複するので、作り直しはトラック名を並べる)。
`cut.py ... grain` のように種類を付けると、その種類の断片だけ切り直す。
セットを保存したあとは録音がそのプロジェクトの `Samples/Recorded/` に入る。`stems.py` が見つけられなかったら `recover.py` で取り込む。

- Live セットは API から保存できないので、残すなら Live で ⌘S。
