# Playback — 書き出した動画の再生ソフト

書き出した動画(`../out/xmusic_10th_1920x540.mov`)を、外部モニターに全画面で出して再生する。Swift だけで作ってあり、外部ライブラリは使っていない。

```bash
./build.sh                                   # build/Playback.app を作る
open build/Playback.app --args 動画.mov       # 動画を指定して開く(指定しなければ「動画を開く…」で選ぶ)
build/Playback.app/Contents/MacOS/Playback --self-test 動画.mov   # 画面を出さずに、読めるか・長さ・出力先を確かめる
```

- **窓**: 手元の操作用。上に小さな確認画面、その下に操作が並ぶ。
- **映像の出力先**: つながっている画面の一覧から選び、「外部モニターに全画面で出す」で、その画面いっぱいに枠なしで映像を出す(比率は保ち、余りは黒)。
  もう一度押すか Esc で止まる。Esc は出力している間だけ Mac 全体のホットキーにしてあるので、ほかのアプリが手前にあっても、入力欄にカーソルがあっても効く(その間、ほかのアプリには Esc が届かない)。外部の画面があれば、最初からそれが選ばれている。画面が抜かれたら出力は自動で閉じる。
- **音の出力先(表示だけ)**: Mac でいま選ばれている出力先の名前とサンプリング周波数を出す。Mac 側で切り替えると表示も変わる。このソフトからは切り替えない
  (切り替えは「システム設定 → サウンド」)。動画の音もテスト音も、その出力先から出る。
- **フラッシュ**: 確認画面と出力先の画面を、一瞬白くする(映像が出ているかの確認)。
- **テスト音**: 1 kHz を 1 秒(左 → 右 → 両方 の順に 0.33 秒ずつ)。
- **映像の明るさ**と**音量**: それぞれ別のスライダー(0〜100%)。映像は 0% で真っ黒、音は 0% で無音。手で好きな所へ動かせる。
  「両方フェードアウト」「映像だけ」「音だけ」は、いまの値から 0% まで、欄の秒数(既定 5 秒)かけてなめらかに下げる。途中でもう一度押すか、スライダーを動かすと止まる。
  「100% に戻す」と「頭に戻す」で元に戻る。フェードしても再生は止めない(止めるのは再生ボタンで)。
- **キー**: スペース = 再生/停止、←→ = 5 秒、Esc = 出力を止める、⌘O = 動画を開く。

## 確認

- `PLAYBACK_TEST=1 build/Playback.app/Contents/MacOS/Playback 動画.mov`: いちばん最後の画面へ全画面で出して 4 秒再生し、出力先の窓の位置と届いたコマ数を出して終わる(外部の画面に実際に 4 秒映る)。
- 絵は `AVPlayerLayer` ではなく、再生機から取り出したコマを両方の画面に貼っている(1 台の再生機を 2 つの `AVPlayerLayer` につなぐと、片方にしか絵が出ないため)。
